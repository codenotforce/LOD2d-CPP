# Reference-epoch E0 calibration (schema v5)

This directory is generated by `bench_helmholtz_reference_epoch_e0` for the
localized smooth R1 case at `kappa=16`, coarse level 3, and reference level 5.

The five numbered artifacts correspond exactly to E0.1--E0.5 in
`HELMHOLTZ_ADAPTIVE_LOD_PLAN.md`.  The direct candidate Helmholtz solve used by
artifact 04 is an isolated small-mesh validation only; the production
reference-epoch runner does not expose such a solve.

The frozen `theta_loc_usr` and `C_rel_usr` are empirical implementation-study
parameters.  They are not rigorous continuous reliability constants and must
not be retuned per production case.
